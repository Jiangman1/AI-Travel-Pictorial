# 简历项目介绍（仿 SpeakEasy 模板）

---

**项目三：AutoMarketing**  
**基于 LangGraph 的智能自动营销系统**

**技术栈：** LangGraph + LangChain + LLM 结构化输出 + 百炼 DashScope 多模态生图 + Playwright RPA + FastAPI + MCP + 百度图片爬虫 + ReAct Agent

**项目时间：** 2025/3 — 2025/5

---

## 一、项目背景

一款面向新媒体运营与内容营销场景的 AI 自动营销助手，实现旅行类头条图文的「文案生成 → 智能配图 → 自动发布 → 效果预览」全链路自动化。系统依托 LangGraph 框架构建状态化工作流，集成大语言模型文案生成、百炼 AI 生图、百度图片爬虫与 Playwright 浏览器自动化，打通「写-图-发-览」闭环，显著降低运营人员手动撰写、找图、排版与上传的时间成本。

---

## 二、核心工作职责

**1. 构建端到端营销内容生产 Pipeline：** 设计「主题输入 → 文案生成 → 配图路由 → 内容校验 → 自动发布 → HTML 预览」全链路流程，基于 LangGraph StateGraph 编排 6 个业务节点，贯通从用户输入到头条发布的闭环系统，支持异步工作流调度与状态持久化流转。

**2. 多路径配图与条件分支系统设计：** 基于 LangGraph 构建可扩展的工作流状态机，统一调度 AI 生图（百炼 qwen-image-2.1-pro）与百度图片爬虫（acjson 接口）双通道配图模式，实现 `image_source` 参数驱动的动态路径切换；设计发布前校验节点，保障标题、正文、图片路径完整性，支撑复杂业务场景下的灵活流转。

**3. LLM 结构化文案引擎开发：** 基于 LangChain + Pydantic + JsonOutputParser 约束模型输出格式，设计旅行图文专用 Prompt 模板，稳定生成 title（≤30 字）、content（≤800 字）、site（地点关键词）三要素；采用流式输出提升交互体验，确保下游配图与发布节点拿到结构化、可解析的数据。

**4. RPA 自动发布与 MCP 协议集成：** 基于 Playwright 实现今日头条号后台自动发文，含 Cookie 登录态持久化、元素显式等待、弹窗关闭与多图批量上传；将文案生成、AI 生图、头条发布封装为 3 个 MCP Tool，配合 LangChain ReAct Agent 实现自然语言驱动的对话式全流程，并提供 FastAPI + React、Streamlit 双端 UI 接入。

---

## 三、工作成效

**1. 全链路自动化落地：** 实现从主题输入到头条发布的一站式自动化，运营人员仅需输入地点关键词（如「湖北荆州」），系统自动完成文案撰写、配图获取与平台发布，单条内容生产流程由人工 30～60 分钟缩短至 3～5 分钟。

**2. 双通道配图灵活切换：** 支持 AI 生图（1 张，2048×2048，风格统一）与百度爬虫（最多 4 张，真实场景感强）两种模式，通过环境变量或 API 参数一键切换，配图成功率达 95% 以上，满足不同运营场景需求。

**3. 多接入方式高效协同：** 基于 LangGraph 统一状态机，同时支持 FastAPI REST API、Streamlit 管理页与 MCP 对话式 Agent 三种接入方式；HTML 预览采用 base64 内嵌图片，无需额外静态资源服务，前端可直接渲染图文效果，提升内容审核与发布确认效率。
